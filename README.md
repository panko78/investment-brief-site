## 自动更新时间
GitHub Actions 使用 UTC：
- `00:10 UTC` ≈ 北京时间 08:10
- `08:10 UTC` ≈ 北京时间 16:10

也可以进入 **Actions → Update market dashboard → Run workflow** 手动刷新。
